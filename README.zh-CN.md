# 富粘贴（Rich Paste for Hermes）

把网页、截图、文件粘进 Hermes Desktop，按你想的样子带进对话：标题、链接、列表、表格、代码变成
Markdown；发给模型时，每张图**放在它在文字里的位置**，而不是全堆在消息末尾。

[English](README.md)

## 为什么要做

Hermes 每轮用户消息的结构是「所有文字在前，所有图在后」。一条消息里几段话各配几张图时，模型只能猜
哪张图属于哪一段，经常猜错。同一批合成监控截图，问 kimi-k3「每台机器的 CPU 读数」（每组 5 轮 × 6 个读数）：

| 场景 | Hermes 现行格式（图全在末尾） | 富粘贴（图文交错） |
|---|---|---|
| 一段一图 | 30/30 | 30/30 |
| 一段多图或无图 | 18/30 | 30/30 |

现行格式的典型错法是把「2 张、1 张、3 张」读成「2、2、2」。复跑脚本：`bench/replay_experiment.py`。
这不是提示词或技能能解决的：图放在哪是 Hermes 组请求时定的，所以插件直接改写发出去的请求（`llm_request` 中间件）。

## 它做什么

- **网页粘成 Markdown**：在浏览器里复制一段网页，粘进输入框。图文交错、表格、成段的文档直接转换，
  输入框下方给「撤销」；只有几个链接、一个列表这类轻格式时，给「转为 Markdown」按钮。设置里可选
  智能、总是转换、从不自动。
- **网页里的图一起带上**：插件后端把图下载到本机缓存，草稿里显示成 Markdown 图片。输入框上方列出
  「将随消息发送的网页图」，点 × 可去掉。页面里有正常大小的图时，96 像素及以下的小图（头像、图标）不带。
  SVG 转成 PNG。
- **截图记住位置**：粘贴截图时照常挂附件，同时在光标处补一个「截图 N」块（Desktop 自己的 `@image:` 块，
  整块选中、移动、删除）。发出去的消息在这个位置写成 `[截图 1]`。
- **访达里复制的文件和文件夹，一次多个也行**：插入 Desktop 自己的文件块、文件夹块、图片块；
  文件作为文件附件发出，文件夹作为 `@folder:` 引用，图片按位置交错。
- **TIFF、HEIC、BMP、AVIF 发送时转成 PNG**（Raycast 剪贴板历史里的图是 TIFF，聊天里会显示成裂图）。
- **点块预览**：可放大、可播放音视频，带「在访达中显示」「替换…」。
- **音频转写**：粘贴音频后点「转写」，用 Hermes 自己的语音转文字，在音频块下面写 `> 转写：…`。
  第一次需要下载模型、或要把音频上传到云端时，先问你。
- **预览**：看 Markdown 草稿发出去后的排版。
- **图文交错**：请求发给模型前，把每张图移到它的标签后面。只改发出去的请求，不改会话历史；
  出任何意外都原样放行。Hermes 的文字模式（判断模型不能看图时）也支持：把每张图的描述移到对应标签后面。

界面默认英文，Desktop 语言设为中文时显示中文（繁体中文也显示简体）。

## 安装

```bash
hermes plugins install rich-paste            # 进入插件目录之后
# 或直接从本仓库装：
hermes plugins install ZhenningLang/rich-paste
```

然后：

1. 重启网关（`hermes gateway restart`）：中间件和下载后端随网关加载。
2. 在 Desktop 打开插件的桌面部分（**Capabilities → Plugins**，或在命令面板搜「Rich Paste」），再运行
   **Reload desktop plugins**。
3. 设置在 **设置 → 插件 → 富粘贴**。

更新插件后两步都要再做一次（重启网关、重载桌面插件）。插件会自己检查后端版本：后端比桌面部分旧时，
输入框下方出现「重启网关」提示和按钮。

### 建议：让能看图的模型直接看原图

Hermes 判断模型不能看图时会走文字模式：先把图描述成文字。如果你的模型其实能看图（例如 kimi-k3），
在 `~/.hermes/config.yaml` 设：

```yaml
model:
  supports_vision: true
```

这样图片直接进请求，交错效果最好。插件不会替你改 Hermes 配置。

## 设置

| 设置 | 默认 | 说明 |
|---|---|---|
| 粘贴网页时 | 智能 | 智能 / 总是转换 / 从不自动 |
| 限制每次下载的张数 | 关 | 打开后每次最多 N 张（默认 10），其余保留为链接。关着时每次也最多自动下载 50 张，点「再下载 N 张」才下其余的 |
| 限制每张图的大小 | 关 | 打开后可填每张最大几兆（默认 10）。后端不保留超过 20 MB 的图 |
| 自动删除下载的图片 | 开 | 删除超过保留天数的缓存，只删插件自己建的日期目录 |
| 保留天数 | 7 | |
| 存放目录 | `$HERMES_HOME/cache/rich-paste/` | 图放在它下面的 `rich-paste-cache/<日期>/`。不在你家目录下的目录，后端不用 |
| 本机转写模型 | 跟随 Hermes | 快（base，约 150 MB）、较准（small，约 490 MB）、最准（turbo，约 1.6 GB）；只管本机转写 |

## 插件在你电脑上做什么（披露）

- **联网**：后端只下载你粘贴的网页里的图，只走 http(s)。拒绝本机回环、内网、链路本地、组播和保留地址，
  每次重定向都重新检查；每次粘贴最多自动下载 50 张（点「再下载 N 张」才下更多）、每张最多 20 MB；只收 PNG、JPEG、GIF、WebP（SVG 转成 PNG）。
  防盗链返回 403 时，带上图片自己网站的 Referer 重试一次。走 HTTP 代理，或 Clash、Surge 这类 fake-ip 代理
  （所有域名解析成 `198.18.x.x`，只在 DNS 返回时放行）时，真实去向由代理决定，插件只拦得住网址里直接写的地址。
  没有其他联网，没有统计上报。
- **系统命令**：粘贴里有文件时，后端运行一次 `/usr/bin/osascript`（3 秒超时），只读 macOS 剪贴板里的
  文件地址（`public.file-url`，最多 20 条），不读剪贴板里的文字和图片。
- **读插件目录以外的文件**：发送时，你加的 TIFF/HEIC/BMP/AVIF 图片附件会被读出（不超过 50 MB）、
  转成 PNG 存进缓存目录。发送时，消息里的图片附件会被算 SHA-256（每个不超过 50 MB，只看图片扩展名），用来让每个
  「截图 N」块找到自己的图。Desktop 存成 `composer-pastes/pasted_content_*.txt` 的长粘贴会被读出长度和前 200 字
  （不超过 4 MB），用来找出转换替换的是哪一段。你选择转写的音频交给 Hermes 的语音转文字（本机或云端，按你的 `stt` 设置）。
- **用到的 Hermes 内部接口**：转写调用 Hermes 的 `tools.transcription_tools`（含 `_get_provider`），
  它变了就提示「状态未知」、什么都不做。点块和复制恢复读 Desktop 输入框引用块的 `data-ref-*` 属性，
  Desktop 改了这两项就不生效。
- **粘进来的文字不是指令**：网页里的 `@file:`、`@url:`、`@diff` 会在 `@` 后加一个看不见的 U+2060，
  Hermes 不会把它们当引用展开（读本机文件、抓网页）。网页里指向本机路径（`file:`、`/Users/…`）的图
  不会被读取，也不会作为附件发出。

## 已知限制

- 只在 macOS 上实测。访达复制的文件路径来自 macOS 剪贴板；其他系统请把文件拖进输入框。
- 发出的标签是 `[截图 1]`，前后各一个看不见的 U+2063，消息末尾还有一个看不见的「共几张图」。图片附件按标签
  顺序排，第 k 个标签对第 k 张图。标签和图对不上时（删过截图的附件，或 Hermes 读不出某张图），写成
  `[截图 1：未对上的附件]` 或图留在末尾，不会放错位置。仍有一个缺口：截图靠粘贴时记下的指纹找自己的图；
  没有指纹时（插件重载后，或截图超过 20 MB）按顺序对位，这时如果你删了它的附件、又用 + 加了一张别的图，
  标签可能指到那张图。
- 粘贴的网页超过 512 KB 或 20000 个元素时不转换，提示「网页内容太大」。
- 自动删除只删缓存文件；过了保留天数，历史会话里这些图显示不出来。已给出的回答不受影响。
- Desktop 连远程 Hermes 时，网页图下载在远端机器上。
- 发送前的预览是输入框上方的一条图片列表，不是附件栏里的卡片：插件 SDK 没有往附件栏加卡片的接口。

## 开发

```bash
npm install
npm run build        # desktop/src → desktop/plugin.js（打包产物提交进仓库）
npm test             # node --test：转换器快照、记号、中间件、插件胶水、多语言
uv run --no-project --with pytest --with fastapi --with httpx --with pillow --with resvg-py python -m pytest tests
hermes plugins validate . --install-deps
bash verify.sh       # 以上全部
```

`tests/convert/` 是几段真实网页的 HTML 摘录和期望的 Markdown，来源和许可见 `tests/convert/SOURCES.md`。
